## What Guardian does

Guardian is a security layer that sits between you and your AI assistant. Once connected, your assistant will **automatically** run every message, file, and image you share through Guardian's scanners before it responds — catching leaked API keys, credit card numbers, national IDs, and hidden prompt-injection attacks.

You don't run commands or click "scan." Guardian works by teaching your assistant a rule it follows on its own: *scan first, respond second.*

## The three tools your assistant gains

Once connected, your assistant has three new capabilities it uses on your behalf — you never call these by name yourself.

| Tool | Fires when you... | Catches |
|---|---|---|
| `scan_prompt` | Send any chat message | API keys, credit cards, national IDs, `.env`/secrets, prompt injection |
| `scan_document` | Upload a file (ZIP, PDF, `.env`, `.txt`, `.csv`, `.json`, `.yaml`) | Leaked secrets inside archives, hidden injection text in PDFs |
| `scan_image_url` | Upload or share an image | Invisible/hidden prompt-injection text inside images (OCR-based) |

Read [How Scanning Works](/how-scanning-works/overview) for exactly what happens under the hood, with real example conversations.
